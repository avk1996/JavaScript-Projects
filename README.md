# 🎮 Tic-Tac-Toe

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**. ✨

## 🚀 Features

* 🎯 Two-player gameplay
* 🏆 Automatic win & draw detection
* 🔄 Restart game option
* 📱 Responsive design
* 🎨 Clean and simple UI

## 🛠️ Tech Stack

* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting a cell.
3. Get **3 marks in a row** to win! 🏆
4. If all cells are filled without a winner, it's a draw. 🤝
